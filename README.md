# tmux-python organization defaults

GitHub reads the community health files here for every repository in the
[tmux-python](https://github.com/tmux-python) organization that does not carry
its own, and renders [profile/README.md](profile/README.md) on the organization
page.

| Path | What it is |
| --- | --- |
| [profile/README.md](profile/README.md) | Public profile rendered on [github.com/tmux-python](https://github.com/tmux-python) |
| [PULL_REQUEST_TEMPLATE.md](PULL_REQUEST_TEMPLATE.md) | Default pull request template for repositories without their own |
| [AI_POLICY.md](AI_POLICY.md) | How the `libtmux` and `tmux-python` projects treat AI tools, linked by the template |
