# tmux-python

Python libraries and tools for [tmux](https://github.com/tmux/tmux): typed
control over servers, sessions, windows, and panes, declarative session
workspaces, and Model Context Protocol integration.

## Packages

| Project | What it does | PyPI | Documentation |
| --- | --- | --- | --- |
| [`libtmux`](https://github.com/tmux-python/libtmux) | Typed Python API and `pytest` plugin for tmux servers, sessions, windows, and panes | [PyPI](https://pypi.org/project/libtmux/) | [libtmux.org/en/py/](https://libtmux.org/en/py/) |
| [`tmuxp`](https://github.com/tmux-python/tmuxp) | Declarative session manager that loads and freezes tmux workspaces from YAML or JSON | [PyPI](https://pypi.org/project/tmuxp/) | [tmuxp.git-pull.com](https://tmuxp.git-pull.com/) |
| [`libtmux-mcp`](https://github.com/tmux-python/libtmux-mcp) | Model Context Protocol server for inspecting and driving tmux from AI tools | [PyPI](https://pypi.org/project/libtmux-mcp/) | [MCP docs](https://libtmux.org/en/py/latest/mcp/) |

## Ports in other languages

The sister [`libtmux`](https://github.com/libtmux) organization hosts ports of
`libtmux` in Rust, Go, TypeScript, C++, Swift, JVM, .NET, Ruby, Lua, BEAM,
Haskell, OCaml, Lisp, Julia, Perl, Raku, and PowerShell, documented at
[libtmux.org](https://libtmux.org/).
